# Feature Specification: Home Launcher and Universal Return

**Status**: Superseded by Spec 015

> **Superseded by Spec 015 on 2026-09-05.** With no session to restore, a universal return-home
> action is unnecessary: the desktop is always underneath, and "home" is closing the active
> application. The curated desktop launchers delivered by Spec 015 cover this feature's
> remaining value.

Provide a TV-friendly launcher/home experience that starts Kodi, Brave/Zuzz, Steam, and future external apps. A universal controller action must close or minimize the active external app and reliably restore the media home using the simplest maintainable mechanism.
