# Feature Specification: On-Screen Keyboard and Pointer

**Status**: Reduced by Spec 015

> **Reduced by Spec 015 on 2026-09-05.** Pointer control is already satisfied by the Spec 008
> DualSense mapping. Text entry is deferred to Spec 016 (phone-based remote input) after Spec 009
> established that GNOME's on-screen keyboard depends on application cooperation the browser did
> not reliably provide. Whatever Spec 016 does not cover is all that remains here.

Make browser text entry and pointer-dependent websites usable from the couch. Provide a controller-triggered, visible on-screen keyboard and a usable pointer/click mode; test that they work in Brave without unexpectedly obscuring video playback.
